ตัวดำเนินการเปรียบเทียบ

(Comparison Operators)

หัวใจสำคัญของการสร้างเงื่อนไขในภาษา Python ที่ใช้สอนให้คอมพิวเตอร์รู้จัก "คิด" และ "ตัดสินใจ"

คอมพิวเตอร์ตัดสินใจอย่างไร?

ในการเขียนโปรแกรม เรามักต้องให้ระบบเลือกทำสิ่งต่างๆ ตามเงื่อนไข เช่น
"ถ้ามีเงินมากกว่าราคาสินค้า ให้ซื้อได้"

เราจึงต้องใช้ ตัวดำเนินการเปรียบเทียบ เพื่อนำข้อมูล 2 ฝั่งมาเทียบกัน

ผลลัพธ์มีแค่ 2 สถานะ (Boolean)

True

เมื่อเงื่อนไขเป็น จริง

False

เมื่อเงื่อนไขเป็น เท็จ

==

เท่ากับ (Equal)

ตรวจสอบว่าข้อมูลทั้งสองฝั่งมีค่า เท่ากัน หรือไม่

10 == 10 # True

5 == 8 # False

!=

ไม่เท่ากับ (Not Equal)

ตรวจสอบว่าข้อมูลทั้งสองฝั่งมีค่า ต่างกัน หรือไม่

10 != 5 # True (ต่างกันจริงๆ)

7 != 7 # False (มันเท่ากัน)

>
<

มากกว่า / น้อยกว่า

เปรียบเทียบปริมาณเชิงคณิตศาสตร์

100 > 50 # True (100 มากกว่า)

20 < 20 # False (มันเท่ากัน ไม่ได้น้อยกว่า)

>=
<=

มากกว่าหรือเท่ากับ / น้อยกว่าหรือเท่ากับ

รวมกรณีที่ตัวเลข เท่ากัน เข้าไปด้วย

18 >= 18 # True (อายุ 18 พอดีถือว่าผ่าน)

0 <= 5 # True (0 น้อยกว่า 5)

จุดระวัง! = ไม่เหมือน ==

= (ตัวเดียว)

ใช้ กำหนดค่า ให้ตัวแปร

score = 100

== (สองตัว)

ใช้ เปรียบเทียบ ค่า

score == 100

คณิตศาสตร์ & การเปรียบเทียบ

คอมพิวเตอร์จะคำนวณตัวเลขให้เสร็จก่อน แล้วจึงนำผลลัพธ์มาเปรียบเทียบ

# (5 คูณ 2) เท่ากับ 10 หรือไม่?

(5 * 2) == 10 -> True

# (10 หาร 2) มากกว่า 3 หรือไม่?

(10 / 2) > 3 -> True

เรียนรู้ทฤษฎีครบแล้ว!

ถึงเวลานำความรู้เรื่อง ตัวดำเนินการเปรียบเทียบ ไปใช้ปกป้องป้อมปราการในมินิเกมของเราแล้ว

สไลด์ 1 / 10
